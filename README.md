🎬 Netflix Data Science Analysis & Machine Learning Project

📌 Project Overview

This project is a Data Science and Machine Learning project based on the Netflix Titles dataset.

The main purpose of this project is to explore and analyze Netflix Movies and TV Shows using Data Analysis, Exploratory Data Analysis (EDA), Data Visualization, and Machine Learning techniques.

The project focuses on identifying useful patterns and insights from Netflix content based on release year, country, genre, rating, type, and duration.

This project provides practical experience in working with a real-world dataset and presenting the results through different visualizations.

---

🎯 Project Objectives

The main objectives of this project are:

- To understand the Netflix dataset.
- To perform data cleaning and preprocessing.
- To analyze Netflix Movies and TV Shows.
- To identify the distribution of Movies and TV Shows.
- To analyze Netflix content by release year.
- To identify the top countries producing Netflix content.
- To analyze the most common Netflix genres.
- To study the distribution of content ratings.
- To analyze title duration.
- To identify relationships between numerical variables.
- To create meaningful data visualizations.
- To apply a basic Machine Learning classification model.
- To evaluate the Machine Learning model.
- To present the complete Data Science workflow in a Jupyter Notebook.

🧹 Data Cleaning

Data cleaning is an important step in this project.

The dataset is checked for:

- Missing values
- Duplicate records
- Incorrect data formats
- Empty values
- Inconsistent values

Missing information is handled appropriately before performing analysis.
